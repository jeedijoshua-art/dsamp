## 2. Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability or potential exposure:

1. **Do not create a public GitHub Issue.**
2. Report the issue privately to the maintainer via GitHub Private Vulnerability Reporting or by contacting Joshua Jeedi through the email listed on his GitHub profile ([@jeedijoshua-art](https://github.com/jeedijoshua-art)).
3. Please include:
   - A description of the vulnerability.
   - Exact steps or script to reproduce the issue.
   - The potential impact.

We will review the report promptly and coordinate a patch prior to any public disclosure.
